# Autonomous Colo Scout

Crusoe Recursive Agents Hackathon (October 17, 2026).

An autonomous, evidence-based agent system for investigating GPU-ready data center colocation opportunities.

## Hackathon MVP

- Manager agent plans and delegates research tasks.
- Specialist agents investigate sites, infrastructure, and evidence.
- Task state persists, and missing evidence triggers bounded follow-up work.
- Inference uses Crusoe Managed Inference.
