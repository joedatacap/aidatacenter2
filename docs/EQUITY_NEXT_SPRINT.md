# Next equity sprint: evidence before more dashboard surface

As of 2026-11-26. Goal: nine reviewable company decisions using comparable denominators, executable source intake and honest prospective accountability.

## Priority 0 — release correctness

1. **Close the nine-company ledger.** All nine files have landed, but complete numerical coverage has not. Inspect `neocloud/data/equity` at release; prioritize withheld metrics and contract/component bridges instead of adding empty scenario slots. Existing filings for every company are already discoverable—do not call an unfinished extraction a disclosure gap. Validate all six modeled fields, year/scenario uniqueness, source IDs, periods and formula identities. Distinguish gross profit fully burdened with D&A from issuer subtotals; EBITDA including SBC from adjusted EBITDA. Acceptance: nine status rows with direct links and machine-validated models or explicit withheld outputs.
2. **Reconcile capitalization once, reuse everywhere.** A+B/common, nominal prefunded warrants, treasury, issued ATM shares, options, converts, project minorities and subsequent events need one dated instrument bridge. For NBIS resolve the $28M internal debt discrepancy and Citi draws; for APLD apply the project preferred distribution/redemption waterfall; for AGPU avoid counting nominal warrants twice. Acceptance: all valuation widgets use the same denominator/convention and show why a qualified historical EV is not current EV.
3. **Resolve market-data rights before recurrence.** Use an authorized provider/export with explicit display, derived-data, storage and historical benchmarking permissions. Keep public filing research independent of provider snapshots. Do not turn the current Stock Analysis observations into a scraper or competing database. Acceptance: written source-rights metadata and a complete sample session for all nine plus QQQ/NVDA; no credentials in static output.

## Priority 1 — make each investment case falsifiable

4. **Build dated cash-use bridges.** For each company connect construction payments, tenant deposits/collections, drawn and undrawn financing, debt maturities and minimum cash. Show both reported figures and scenario inputs. For NBIS, $6–11.25B of capex outside management's expected financing coverage is not the entire liquidity gap; modeled negative FCF already includes prepayment movements. Acceptance: no cash-plus-commitment totals or duplicated customer funding.
5. **Replace cohort shortcuts with project drivers.** Dedicated GPU clouds: available/billed GPU or MW cohorts, realized prices and replacement costs. Landlords: tenant acceptance, rent, remaining cost and project residual ownership. Mixed miners: separate mining from contracted AI revenue. SHAZ/WYFI need acceptance, funding and minority/share bridges, not annualized contract headlines. Acceptance: every base-case change has one driver, source or explicitly selected assumption and a downside sensitivity.
6. **Track actual revisions.** Keep original target, revision date, observation and commercial outcome separately. Prioritize NBIS February ARR/Q2 New Jersey, APLD year-end delivery, IREN acceptance, AGPU amended Georgia economics, and SHAZ commissioning-to-billing. A missed announcement is not proof of missed delivery. Acceptance: one evidence-linked upgrade and downgrade condition per company, linked to the saved report version.

## Priority 2 — prospective accountability and storage

7. **Publish immutable versions before scoring.** Bind the content hash to an actual public-release timestamp. First entry is the first required observed session after publication, not a convenient historical price. At 1w/1m/3m/6m/12m compare identical sessions against QQQ, NVDA and the frozen peer cohort; missing prices stay pending and no survivors replace missing peers. Do not score Hold/Sell as implicit short trades. Acceptance: replay tests for holidays, missing sessions, splits, revised prices and unreleased reports.
8. **Evaluate database integration separately.** The current Site has no bindings. The separate database catalog is useful architecture context, not authorized app data. Before any transfer, establish permitted fields/records, provenance, rights, read-only query scope and a versioned publication manifest. Prefer reviewed public-filing records first. Acceptance: explicit authorized mapping and rollback/export audit; no claim of connected production persistence before a real binding and read path exist.

## Definition of done

Nine company statuses; six transparent forward metrics where supportable; one shared capital bridge per company; dated source links; reproducible scenario checks; approved quote/benchmark provenance; actual published report versions; honest pending performance. No numerical target is forced where project cash rights and dilution cannot support one.
